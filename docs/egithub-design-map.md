# eGitHub → GitHome

Референс — [eGitHub / Million Review](https://www.egithub.com/). Исследование выполнено в Paseo Browser с рабочим аккаунтом. Операции записи (комментарий, слияние, отметка просмотра) не отправлялись.

## Карта экранов

| Экран eGitHub | Наблюдаемый сценарий | Адаптация для GitHome |
| --- | --- | --- |
| Вход, два шага | Сначала команда для получения токена, затем отдельное поле и кнопка подключения | На пустой главной одна понятная точка входа. Сохраняем существующую форму GitLab для нескольких серверов, PAT и Jira |
| Главная | Центрированный блок, открытие по ссылке/короткой записи, поиск, переключатель Created / To review, плоские строки с состоянием, репозиторием, номером и возрастом MR | То же ядро. Используем синтаксис GitLab и оставляем проекты доступными в выдвижной панели |
| Меню аккаунта | Профиль, System / Light / Dark, выход | Оставляем подключения и отдельные настройки GitHome, используем компактные кнопки вместо крупной шапки |
| Overview PR | Слева поиск и очередь PR. В центре заголовок, состояние, автор, ветки, табы Description / Discussion / Commits, список файлов с дельтой. Справа Reviewers / Checks / Branch / Labels | Обзор MR с деревом изменённых файлов слева и метаданными GitLab справа. История коммитов и обсуждения в табах, полный diff ниже на той же странице |
| Changes PR | Отдельный режим. Узкая верхняя панель с путём и действиями, слева ресайз дерева, справа diff-карточки. Back возвращает в обзор, выбор файла прокручивает diff | Разделяем обзор и изменения через URL. Переиспользуем виртуализацию, просмотренные файлы, дифф-поиск, контекст и inline-комментарии GitHome |
| Режим по коммитам | Тот же редактор, слева вместо дерева список коммитов. Выбор меняет URL и набор изменений | Показываем реальные коммиты MR. Не подменяем коммиты версиями diff: в GitLab это разные сущности |
| Меню редактора | Unified / Split, Zen, перенос, счётчики, тема и размер кода, скрытие тестов/генерации | Переносим только настройки, поддержанные нашим рендерером. Не показываем переключатели без рабочего действия |
| Поиск и меню файла | Поле поиска кода в шапке. В заголовке файла сворачивание, путь, числа, Viewed и меню | Переиспользуем поиск кода и все доступные файловые действия, делаем их компактнее |
| Мобильный diff | В шапке вмещается контекст MR, дерево выдвигается одной кнопкой | Сворачиваем очередь и дерево. Главный контент остаётся одноколоночным |
| Прямой URL коммита | Сразу открывается редактор изменений выбранного коммита | Сценарий отдельного URL commit не смешиваем с существующим переходом проекта или MR |

## Дизайн-система

- Тёмный рабочий фон около `#101010`, панели чуть светлее, границы на один пиксель, без стеклянных градиентов и крупных теней.
- Белые заголовки и приглушённый серый второстепенный текст. Мятный у открытых MR и добавленных строк, красный у удалённых, тёплый оттенок у изменённых путей и контекста diff.
- Верхняя строка примерно 52 px, боковая панель около 275 px на 1280 px. Панели разделены границами, а не зазорами между большим набором карточек.
- Активный таб обозначается заливкой в компактном сегментированном контроле. Основные размеры текста 13–15 px, заголовок 24–26 px. Пути, номера и код читаются отдельно от прозы.
- Приоритет — те же рабочие маршруты. Главная → обзор → изменения → назад. На узком экране боковые разделы доступны по кнопке.

Контрольный PR — [обзор](https://www.egithub.com/acacode/swagger-typescript-api/pull/696) и [редактор](https://www.egithub.com/acacode/swagger-typescript-api/pull/696/changes). Скриншоты с пользовательской очередью сохранены отдельно от репозитория.

## Что перенесено

- Полноширинная главная с очередями «На моё ревью» и «Мои MR», постоянной панелью проектов и недавно открытыми MR. Палитра `Ctrl+K` ищет проекты и MR и поддерживает ссылки и запись `group/project!42`.
- Обзор с деревом файлов слева, описанием, обсуждением и коммитами в центре, ревьюерами, лейблами и пайплайнами справа. В обзоре сразу доступен diff всех файлов MR.
- Редактор `?view=changes` с изменяемой шириной дерева, переходом из списка файлов, поиском по diff, режимом дзен, переносом и размером шрифта. Список коммитов позволяет открыть отдельный diff. Он доступен для чтения, а inline-ревью остаётся в режиме файлов MR.
- Компактные вкладки MR, светлая и тёмная темы, сворачиваемые панели на узких экранах.
- Менеджер пайплайнов в обзоре MR с переключением запусков, фильтрами задач, графом этапов и логами.

Не перенесены в этой версии split diff, автоматическая группировка файлов по назначению и отдельные входы по GitLab-ссылке на ветку или коммит. Снимки этих сценариев сохранены как референс.
